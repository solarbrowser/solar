# Filter lists

Snapshots (13 Nov 2026) of the lists the content blocker reads (src/gui/Blocker.cpp), in Adblock Plus syntax:

- easylist.txt — EasyList, https://easylist.to/ (dual licensed: GPLv3 / CC BY-SA 3.0)
- easyprivacy.txt — EasyPrivacy, https://easylist.to/ (same licences)
- easylist-cookie.txt — EasyList Cookie List (Fanboy's Cookiemonster), https://easylist.to/ (same licences)

They are embedded in the binary as data and are not linked as code. To update: download the files again from https://easylist.to/easylist/easylist.txt,
https://easylist.to/easylist/easyprivacy.txt and https://secure.fanboy.co.nz/fanboy-cookiemonster.txt and replace them.
